# Instrucciones del proyecto

Las instrucciones completas y obligatorias están en [AGENTS.md](AGENTS.md).
Se conserva este archivo con el nombre solicitado; `AGENTS.md` es la fuente canónica
para las herramientas que reconocen automáticamente instrucciones de agentes.

Incluye PHP MVC, Alpine.js, Tailwind, archivos pequeños, login de SuCasa, base separada,
migraciones automáticas de tablas y columnas, autoguardado y normas de formularios.
