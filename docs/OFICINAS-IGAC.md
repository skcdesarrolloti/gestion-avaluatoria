# Numeral 1: referencias IGAC para Oficina

Al seleccionar Tipo de construcción = Oficina, Tipología IGAC de apoyo reúne
Comerciales y Edificios, incluidos ED.Servicios_Tipo_1, Tipo_2 y Tipo_3.
Se conservan las denominaciones originales; cada opción muestra su categoría.
La categoría se determina por la referencia elegida, también en el servidor,
para unidades principales y anexos. El selector de categoría queda informativo
en Oficina. Ninguna tipología se adopta automáticamente.

Se conserva la selección existente, incluso si pertenece a otra categoría.
Las demás construcciones mantienen su filtrado. La lista contiene referencias
que pueden no corresponder al sujeto: el analista consulta la descripción y las
especificaciones antes de elegir. No se modifican datos del catálogo ni métodos.

Sin migraciones. Publicar el código actualizado mediante el despliegue habitual.
